# 💻 Techno World App — Frontend SPA

React 19 single-page application built with Vite, TypeScript, and Tailwind CSS 4.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite 7
- **Styling**: Tailwind CSS 4 + Lucide React Icons
- **State Management**: Zustand (`AuthStore`) + StoreContext
- **API Client**: Axios with centralized error handling in `src/services/api.ts`

## 🚀 Commands
```bash
# Install dependencies
npm install

# Start Dev Server
npm run dev -- --host

# Build for Production
npm run build
```
